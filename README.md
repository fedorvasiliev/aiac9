# aiac9

Go-приложение-Агент, Сгенеренный при помощи SDD через AI.

## Требования

- Go 1.27+ (если не установлен в этом окружении — поставьте через `brew install go` или https://go.dev/dl/)

## Структура проекта

```
cmd/aiac9/             точка входа (main.go)
internal/cli/          разбор аргументов командной строки, диспетчеризация команд
internal/config/       загрузка конфигурации из переменных окружения
internal/interactive/  консольный wizard-режим (запуск без аргументов)
internal/llm/          общий клиент OpenAI-совместимого chat completions API
internal/kimi/         endpoint провайдера Moonshot AI (Kimi)
internal/deepseek/     endpoint провайдера DeepSeek
internal/promptfile/   парсинг заготовленных промптов из ./prompts
internal/exchangelog/  логирование пар запрос/ответ в ./logs
internal/secretmask/   маскирование значений из переменных окружения
internal/term/         raw-режим терминала (для стрелок в select-шагах)
internal/server/       HTTP-сервер (net/http), маршруты, graceful shutdown
internal/version/      метаданные сборки (версия/коммит/дата), задаются через -ldflags
```

`internal/` закрывает пакеты от импорта извне модуля — это стандартный подход
для приложений, которые не предоставляют публичное Go API.

## Команды

```
aiac9 [-f substr] [-timeout N] запустить интерактивный wizard-режим (LLM)
aiac9 serve [--addr :8080]     запустить HTTP-сервер
aiac9 version                  вывести версию сборки
aiac9 help                     справка
```

### Интерактивный режим

Запуск без аргументов (`aiac9`) включает консольный wizard для общения с LLM
по HTTP API. Провайдер выбирается по имени модели: `deepseek*` — DeepSeek,
всё остальное (включая модель по умолчанию `kimi-k2.6`) — Moonshot AI
(Kimi). Оба используют общий клиент `internal/llm`, отличаясь только
base URL и переменной окружения с ключом.

Все заголовки шагов (label) выводятся жёлтым. На настоящем терминале
select-шаги листаются стрелками вверх/вниз или пробелом (список
закольцован), Enter подтверждает выбор; если stdin не терминал (пайп,
тесты) — выбор по номеру или точному тексту варианта, Enter — принять
вариант по умолчанию.

1. **Шаг A — выбор заготовленного промпта.** Список берётся из файлов в
   `./prompts` **во время выполнения** (не при компиляции) плюс первый,
   всегда доступный вариант «(без промпта)» — по умолчанию. Формат файла:
   заголовки Markdown (`### Заголовок`), каждый — один из `Model`,
   `System prompt`, `User prompt` (может повторяться — каждое вхождение
   станет отдельным сообщением), `Response format`, `Words limit`, `Stop`,
   `Temperature`; регистр заголовков не важен. Если выбран не «(без
   промпта)», сразу после выбора распарсенные значения выводятся в
   терминал таблицей (первая колонка — жёлтая), пустые строки не
   показываются; если значение любого поля длиннее 80 символов, вместо
   таблицы печатается по блоку `Заголовок:`/значение на каждую секцию
   (заголовок блока — жёлтый). `Model` из файла переопределяет модель по
   умолчанию (`kimi-k2.6`) и, тем самым, провайдера; `Response format` и
   `Stop` уходят в соответствующие поля запроса; `Temperature` — в поле
   `temperature` (нечисловое значение молча игнорируется); `Words limit`
   дописывает фразу «Максимальное количество слов в ответе должно быть
   N.» ко всем `User prompt`.
2. **Шаг T (терминальный) — ввод текста.** Пустое значение допускается.
   Если введён непустой текст, он дописывается ко всем `User prompt` (или,
   если промпт не выбирался, становится единственным user-сообщением).
   Enter отправляет собранный запрос.
3. Запрос логируется в `./logs` (см. ниже) сразу перед отправкой — то есть
   лог-файл появляется ещё до получения ответа. Пока ответ ожидается, в
   терминале крутится анимированный спиннер. Ответ модели печатается
   зелёным и дописывается в тот же лог-файл, и wizard возвращается к
   шагу A для следующего запроса.

Спиннер и цвета показываются только на настоящем терминале — в пайпах и
логах (не-tty stdout) вывод остаётся простым текстом без ANSI-кодов.

Выход в любой момент: `exit`/`quit`, `q` на select-шаге, Ctrl+C или
Ctrl+D (EOF).

Требуется переменная окружения с ключом провайдера, который реально
используется — `MOONSHOT_API_KEY` для Kimi и/или `DEEPSEEK_API_KEY` для
DeepSeek (см. `.env.example`); без неё запрос к соответствующему провайдеру
не отправляется. `MOONSHOT_BASE_URL`/`DEEPSEEK_BASE_URL` — опциональное
переопределение адреса API (например, для прокси или локальных тестов).
Значения, полученные из переменных окружения, при выводе на экран и в
логи маскируются звёздочками (`***`).

Таймауты HTTP-клиента (общие для обоих провайдеров): 30 секунд на
установку соединения, 120 секунд — на весь запрос целиком (включая
ожидание ответа).

Флаги интерактивного режима:
- `-f substr` — показывать на Шаге A только файлы из `./prompts`, в имени
  которых встречается `substr` (например, `aiac9 -f w1d4` покажет только
  `any-w1d4.prompt.md` и подобные).
- `-timeout N` — переопределить таймаут ожидания ответа, в секундах
  (по умолчанию 120).

## Быстрый старт

```sh
cp .env.example .env               # заполнить MOONSHOT_API_KEY
go run ./cmd/aiac9                 # интерактивный режим

make run                           # go run ./cmd/aiac9 serve
curl localhost:8080/healthz
```
